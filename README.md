# County Rainfall and Planting Advisory
## Project Summary

This project analyzes rainfall data from five counties, cleans invalid observations, identifies rainfall trends, and recommends suitable planting windows using NumPy.

## How to Run
Open rainfall_analysis.ipynb and run all cells from top to bottom.

# Planting Advisory
1. Most counties experience peak rainfall around April and May.
2. Counties with several dry months should implement water conservation strategies.
3. Planting should be aligned with each county's highest two-month rainfall window.
