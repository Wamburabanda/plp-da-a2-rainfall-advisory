# County Rainfall and Planting Advisory
## Project Summary

This project analyzes rainfall data from five counties, cleans invalid observations, identifies rainfall trends, and recommends suitable planting windows using NumPy.

## How to Run
Open [rainfall_analysis.ipynb](https://colab.research.google.com/drive/1oY6jt9RMZlm-sOWCD-9OJAweJuIDSMCp#scrollTo=p8WG41EI9nwG) and run all cells from top to bottom.

# Planting Advisory
+ Most counties experience peak rainfall around April and May.
+ Counties with several dry months should implement water conservation strategies.
+ Planting should be aligned with each county's highest two-month rainfall window.
